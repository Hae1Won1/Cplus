# 📘 3장 클래스와 객체

## 3-1 객체에 대한 이해

- **객체**
    - 세상 모든 것
    - 본질: **캡슐화**
        - 구성 요소들을 감추어 보호
    - **공개**
        - 객체 간 정보 교환·통신 위해 일부 공개 필요
    - **구성 요소**
        - 상태 → 멤버 변수
        - 행동 → 멤버 함수
- **클래스**
    - 객체 정의하는 **틀/설계도**
    - 멤버 변수(상태) + 멤버 함수(행동) 포함
    - 객체는 클래스에서 생성된 **인스턴스**
    - 같은 클래스라도 객체는 **별도 메모리 공간**을 가짐
    - ⚠️ 클래스 자체를 객체라 부르지 않음

---

## 3-2 클래스 생성

- **클래스 선언**
    
    ```cpp
    class Circle {
        ...
    }; // 세미콜론 필수
    
    ```
    
- **클래스 멤버**
    - 변수 + 함수
    - 멤버 함수는 원형 선언 필요
- **접근 지정자**
    - `public` : 외부 접근 허용
    - `private` : (디폴트) 외부 접근 불가
    - `protected` : 상속 관계에서 접근 허용
- **클래스 구현**
    - 선언부 외부에서 함수 구현 시 `범위 지정 연산자(::)` 사용

---

## 3-3 객체 생성과 활용

- **객체 생성**
    
    ```cpp
    Circle donut; // Circle 클래스 객체 생성
    
    ```
    
- **멤버 접근**
    
    ```cpp
    donut.radius = 1;
    double area = donut.getArea();
    
    ```
    
- 객체는 선언과 동시에 **클래스 크기만큼 메모리 할당**

---

## 3-4 생성자 (Constructor)

- **특징**
    - 객체 생성 시 자동 실행
    - 이름 = 클래스명
    - 리턴 타입 없음 (void 포함 불가)
    - 한 번만 실행됨
    - 오버로딩 가능 (매개변수 개수·타입 달라야 함)
- **예제**
    
    ```cpp
    class Circle {
    public:
        int radius;
        Circle();        // 기본 생성자
        Circle(int r);   // 매개변수 있는 생성자
        double getArea();
    };
    
    ```
    
- **위임 생성자**
    - 초기화 코드를 다른 생성자에 위임
    
    ```cpp
    Circle::Circle() : Circle(1) {}
    Circle::Circle(int r) { radius = r; }
    
    ```
    
- **초기화 방식**
    - 생성자 내부 대입
    - 멤버 이니셜라이저 `: x(a), y(b)`
    - 선언부 직접 초기화 `int x=0;`
- **기본 생성자**
    - 생성자 미선언 시 컴파일러가 자동 생성
    - 단, 생성자가 하나라도 있으면 자동 삽입 ❌

---

## 3-5 소멸자 (Destructor)

- **특징**
    - 객체 소멸 시 자동 실행
    - `~클래스이름()`
    - 매개변수 없음, 오버로딩 불가
    - 리턴 타입 없음
- **실행 순서**
    - 생성자 실행 → 반대 순서로 소멸자 실행

---

## 3-6 접근 지정 (Access Specifier)

- `private` (디폴트) : 클래스 내부에서만 접근
- `public` : 외부 접근 가능
- `protected` : 파생 클래스 접근 가능
- 생성자는 일반적으로 `public` 으로 선언

---

## 3-7 인라인 함수 (inline)

- **목적** : 함수 호출 오버헤드 줄임
- **방법**
    
    ```cpp
    inline int odd(int x) { return x % 2; }
    
    ```
    
- **장점** : 실행 속도 ↑
- **단점** : 코드 중복으로 크기 ↑
- **제약** : 재귀, 반복문 등은 인라인 무시될 수 있음
- **클래스 선언부에서 직접 구현된 멤버 함수** → 자동 인라인 처리

---

## 3-8 C++ 구조체 (struct)

- C와 달리 클래스와 동일한 기능 보유
- **차이점**
    - 기본 접근 지정자: `struct → public`, `class → private`
- 객체 생성 시 `struct` 키워드 불필요

---

## 3-9 바람직한 작성법

- **헤더(.h) / 구현(.cpp) 분리**
    - 클래스 선언: 헤더
    - 함수 구현: cpp
- **중복 include 방지**
    
    ```cpp
    #ifndef CIRCLE_H
    #define CIRCLE_H
    ... class Circle { ... }
    #endif
    
    ```
